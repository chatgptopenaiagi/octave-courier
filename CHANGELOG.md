# Changelog

## 0.1.0

Initial independent Octave Courier release.

- Portable GNU Octave executable discovery and runtime/package inspection.
- Finite real matrix multiplication and square linear solving through file JSON.
- Fixed numerical, statistics, signal-processing and optimisation demonstrations.
- PNG export and explicit trusted local script execution.
- Python API, command-line entry point, typed failures and time limits.
- Windows executable, Linux launcher archive, pure-Python wheel and source distribution.
- Mathematical examples, isolated artifact verification, checksums and CI workflows.

This release extracts and generalises an earlier locally verified integration.
Inherited verification counts are kept distinct from new release-artifact tests.
